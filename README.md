## Download Release APK and Install Manually

We recommend installing CubeLens from the [Google Play store page](https://play.google.com/store/apps/details?id=com.cubiqminds.cubelens&referrer=utm_source=github),
so you receive automatic app updates.

However, if you prefer to install the app directly as an APK package, you can
download the [latest release from this repository](https://github.com/cubiqminds/cubelens-community/releases).
To install it, you need to allow Android to install packages from unknown
sources ([instructions](https://docs.pandasuite.com/essentials/mobile-publishing/android/install-app-from-unknown-sources-on-android-device/)).

Please note the following if you install CubeLens via APK:
- We can only give limited support for this installation method
- The installation will not be automatically updated, you need to manually download
  and install the newest APK to update
- Ensure you don't have CubeLens installed via Google Play store. Otherwise there
  will be inference with the APK-installed version.

## Report Bugs and Request Features

Please use [Issues](https://github.com/cubiqminds/cubelens-community/issues) to
report bugs, request improvements, or share feedback about the CubeLens Android
app. The app is designed for fast cube scanning, AI-assisted solving,
beginner-friendly instructions, and visual guidance through AR or a 3D cube view.

## Before Opening An Issue

Please include your Android version, device model, CubeLens app version, what
you expected to happen, and what actually happened. Screenshots or screen
recordings are especially helpful for scanning, AR guidance, or solving issues.
